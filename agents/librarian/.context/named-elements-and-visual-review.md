# Librarian checkpoint: named elements and visual review

`library/schema/design-elements.json` is the controlled glossary. Every
promoted named element must have a concise definition, authoritative
attribution, source IDs, and record/image association through
`claims.named_elements` and asset `named_element_refs`.

The visual-interpreter's low-token first pass is advisory. Bind an
image-derived term only when the annotation is linked to the exact record and
the packet/museum source supports the term. Do not upgrade probable or
unresolved visual attributions to confirmed historical facts.
